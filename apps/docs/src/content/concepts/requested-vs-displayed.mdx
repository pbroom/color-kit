## Two colors, one value

A user can pick a color no screen can show. Clamping it in place would move
the picker thumb, lose the choice on the next edit, and make undo lie. color-kit
keeps two values instead:

- **requested**: the exact OKLCH color that was asked for.
- **displayed**: the requested color mapped into the output gamut, used only
  to paint.

## Mapping changes chroma only

`toSrgbGamut` and `toP3Gamut` reduce chroma at fixed lightness and hue by
default. Lightness-driven measurements, like contrast regions on a plane, stay
put when the gamut changes.
