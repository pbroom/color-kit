## Parse a color

Every value is an OKLCH [`Color`](/api/core/Color): lightness `l` from 0 to
1, chroma `c`, hue `h` in degrees, and `alpha`. [`parse`](/api/core/parse)
reads any CSS Color 4 string.

```ts title="parse.ts"
import { parse } from 'color-kit';

const coral = parse('oklch(0.7 0.25 30)');
// → { l: 0.7, c: 0.25, h: 30, alpha: 1 }
```

## Can a display show it?

`coral` is outside sRGB and outside Display P3. color-kit keeps the color you
asked for and maps a copy for the display, reducing chroma only, so lightness
and hue hold still.

```ts title="gamut.ts"
import { inSrgbGamut, toCss, toSrgbGamut } from 'color-kit';

inSrgbGamut(coral); // → false
const shown = toSrgbGamut(coral);
toCss(shown, 'oklch'); // → 'oklch(0.7 0.1915 30)'
```

## Is it readable?

Measure contrast on the color you paint.

```ts title="contrast.ts"
import { contrastRatio, parse } from 'color-kit';

contrastRatio(shown, parse('#fff')).toFixed(2); // → '2.90'
```

2.90:1 fails WCAG AA for body text (4.5:1) and for large text (3:1). Try
your own colors. The example paints hex, so it measures with
`{ precision: '8bit' }`, and it blends a translucent color over each
background before measuring, since `contrastRatio` ignores alpha:
