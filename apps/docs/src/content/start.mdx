## Install

<InstallLine />

color-kit is published under the `next` tag until 1.0. The package has no
runtime dependencies on React; `color-kit/react` is an optional entry point.

## Parse a color

Every value in color-kit is an OKLCH `Color`: lightness `l` from 0 to 1,
chroma `c`, hue `h` in degrees, and `alpha`. `parse` accepts any CSS Color 4
string.

```ts title="parse.ts"
import { parse } from 'color-kit';

const coral = parse('oklch(0.7 0.25 30)');
// { l: 0.7, c: 0.25, h: 30, alpha: 1 }
```

## Can a display show it?

`coral` is outside sRGB and outside Display P3. color-kit keeps the color you
asked for and maps a separate copy for the display, reducing chroma only so
lightness and hue hold still.

```ts title="gamut.ts"
import { inSrgbGamut, toCss, toSrgbGamut } from 'color-kit';

inSrgbGamut(coral); // false
toCss(toSrgbGamut(coral), 'oklch'); // 'oklch(0.7 0.1915 30)'
```

## Is it readable?

Contrast is measured on the color the display will actually show.

```ts title="contrast.ts"
import { contrastRatio, parse, toSrgbGamut } from 'color-kit';

contrastRatio(toSrgbGamut(coral), parse('white')); // 2.90
```

<Callout tone="warning">
  2.90:1 fails WCAG AA for body text (4.5:1) and for large text (3:1). The same
  hue at a lower lightness passes; the contrast concept page shows how to find
  that edge as a region instead of by trial.
</Callout>
