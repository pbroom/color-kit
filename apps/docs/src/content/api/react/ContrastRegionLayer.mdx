## Edge cases

- **Lightness and chroma only.** The region is solved in the area's
  lightness/chroma plane. Axes `l` and `c` work in either order; any other
  pair (a hue axis, say) renders an empty layer rather than throwing.
- **The reference defaults to the requested color.** Without `reference`,
  the layer measures every color of the hue against the color being picked,
  which is rarely what a text-on-background check wants. Pass the fixed
  background (or text) color explicitly.
- **Gamut.** Samples and the reference are measured in `gamut` (`'srgb'` by
  default) and paths stay inside it, so the region never promises a color
  the target display cannot show.
- **Thresholds.** `threshold` overrides `level` and `apcaPreset`. With
  `metric="apca"` it is a normalized Lc magnitude: `0.6` means Lc 60.
- **While dragging.** The region is solved synchronously at rest and in a
  shared Web Worker during drags, where available; the last stable region
  stays on screen until a fresh one arrives, so the outline can trail the
  thumb by a frame or two.
- **Removed props throw.** The hybrid solver's props (`lightnessSteps`,
  `chromaSteps`, `hybridMaxDepth`, `hybridErrorTolerance`, `tolerance`,
  `maxIterations`) are type errors and throw a `TypeError` at runtime. Tune
  `initialSamples`, `errorTolerance` and `maxDepth` instead.
