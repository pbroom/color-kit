`@pbroom/color-kit` is the everyday import. Every function takes and returns the same
value, an OKLCH [`Color`](/api/core/types#Color) (`{ l, c, h, alpha }`), so results
compose without conversions in between. It runs in any JavaScript runtime and
has no React dependency. `@pbroom/color-kit/core` is an alias of this entry.

## Domains

- **Conversion.** [`parse`](/api/core/conversion#parse) and
  [`tryParse`](/api/core/conversion#tryParse) read any CSS Color 4 string;
  [`toCss`](/api/core/conversion#toCss) writes hex, `rgb()`, `hsl()`, `oklch()`,
  `oklab()`, `color(display-p3 …)` or `color(rec2020 …)`. `to*`/`from*` pairs cover RGB, HSL,
  HSV, HCT, OKLab and Display P3, with allocation-free `*Into` variants.
- **Gamut.** Membership ([`inSrgbGamut`](/api/core/gamut#inSrgbGamut),
  [`inP3Gamut`](/api/core/gamut#inP3Gamut),
  [`inRec2020Gamut`](/api/core/gamut#inRec2020Gamut)), mapping
  ([`toSrgbGamut`](/api/core/gamut#toSrgbGamut), [`toP3Gamut`](/api/core/gamut#toP3Gamut),
  [`toRec2020Gamut`](/api/core/gamut#toRec2020Gamut))
  and geometry ([`maxChromaAt`](/api/core/gamut#maxChromaAt),
  [`gamutBoundaryPath`](/api/core/gamut#gamutBoundaryPath)) for sRGB, Display
  P3 and Rec. 2020.
- **Contrast.** WCAG ([`contrastRatio`](/api/core/contrast#contrastRatio),
  [`meetsAA`](/api/core/contrast#meetsAA)), APCA
  ([`contrastAPCA`](/api/core/contrast#contrastAPCA)), contrast regions
  ([`contrastRegionPaths`](/api/core/contrast#contrastRegionPaths)) and the
  nearest color that meets a threshold
  ([`ensureContrast`](/api/core/contrast#ensureContrast)).
- **Color difference.** [`deltaEOK`](/api/core/difference#deltaEOK) is the
  Euclidean distance in OKLab (black to white is 1);
  [`deltaE2000`](/api/core/difference#deltaE2000) is CIEDE2000 in CIE Lab D50
  (black to white is 100). Both ignore alpha and take colors outside sRGB.
- **Mixing and scales.** [`mix`](/api/core/manipulation#mix),
  [`interpolate`](/api/core/scale#interpolate) and
  [`generateScale`](/api/core/scale#generateScale) use OKLCH by default. Their
  `space` option accepts `'oklch'`, `'oklab'`, `'srgb'`, `'linear-srgb'`,
  `'display-p3'` and `'linear-p3'`.
  [`lightnessScale`](/api/core/scale#lightnessScale) varies OKLCH lightness while
  keeping chroma, hue and alpha fixed; it has no space option.
- **Manipulation and harmony.** [`lighten`](/api/core/manipulation#lighten),
  [`adjustHue`](/api/core/manipulation#adjustHue),
  [`complementary`](/api/core/harmony#complementary) and friends, all immutable.
  [`saturate`](/api/core/manipulation#saturate) and [`desaturate`](/api/core/manipulation#desaturate)
  clamp chroma only at 0, so wide-gamut colors keep chroma above `0.4`; map
  the result to a gamut when you need it on screen.

The root also re-exports the plane essentials (`definePlane`, `sense`,
`toSvgPath`) and the HCT helpers. The rest of the plane API and all array
interop are on their own entry points only.

```ts title="brand.ts"
import {
  contrastRatio,
  inSrgbGamut,
  parse,
  toCss,
  toSrgbGamut,
} from '@pbroom/color-kit';

const brand = parse('oklch(0.62 0.24 290)');
inSrgbGamut(brand); // → false
const shown = toSrgbGamut(brand); // chroma reduced, lightness and hue kept
toCss(shown, 'hex'); // → '#8a62ff'
// Measure the hex you ship: 8-bit channels, not the unrounded color.
const white = parse('#fff');
contrastRatio(shown, white, { precision: '8bit' }).toFixed(2); // → '3.98'
```
