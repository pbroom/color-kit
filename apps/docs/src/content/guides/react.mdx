## The smallest picker

`Color` owns the state; `ColorArea` and `ColorStringInput` read and write it.
The primitives ship unstyled, so the size and look come from you.

```tsx title="picker.tsx"
import { Color, ColorArea, ColorStringInput } from 'color-kit/react';

export function Picker() {
  return (
    <Color defaultColor="#3b82f6">
      <ColorArea style={{ width: 200, height: 200 }} />
      <ColorStringInput format="oklch" />
    </Color>
  );
}
```
